# Cómo contribuir
1. Cree una rama corta desde `main` (`feat/...`, `fix/...`).
2. Commits con Conventional Commits (`tipo(alcance): descripción`).
3. Abra un Pull Request; otro integrante debe revisarlo y el CI debe estar en verde.
4. Nunca suba credenciales, tokens ni claves.
Más detalle en `docs/GIT_WORKFLOW.md`.
